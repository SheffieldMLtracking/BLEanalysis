# BLEanalysis

Toolkit for processing the BLE bee tag data. This branch contains work done for Finley's
dissertation project.

# Installation

Python 3.12 (not 3.13) is required to run this code, as are previous versions of the
`jax`, `jaxlib` and `tensorflow-probability` packages. To install the correct versions,
run the following:

```shell
pip install pip install "jax==0.4.28" "jaxlib==0.4.28" "tensorflow-probability==0.24.0"
```

The `BLEanalysis` package, located in this repository, also needs to be installed. To do that, run:

```shell
pip install -e .
```
